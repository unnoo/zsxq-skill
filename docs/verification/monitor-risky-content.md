## 实测校准了哪些文档假设

- **翻页边界重叠影响水位线去重**：与 daily-patrol 同源发现——`next_end_time` 含等于导致边界主题重复。场景第 90 行已正确要求"主题按 topic_id、评论按 comment_id 再做一次去重，兜住边界时间点的重复"，本次实测**证实该去重要求是必要的**（不是保守冗余）。原子操作 `group-topics.md` 已补边界去重注。
- **评论字段足够做风险判定**：`get_topic_comments` 返回 `text`/`create_time`/`owner.{name,location}`，可按 create_time 过滤新评论、按 owner 标注发布者。与场景第 3、5 步一致。
- **评论无独立 URL 属实**：评论项无 url 字段，场景第 84 行"评论没有独立 URL → 用其所在主题的链接"表述正确。

不涉及写入。本场景核心红线是"只发现、只上报、绝不自动删除/处置"，测试严格遵守：仅调用 group +topics / get_topic_comments / topic +detail，未执行任何 topic-delete 或其他处置写入。
