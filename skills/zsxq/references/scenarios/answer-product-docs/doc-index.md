# 文档站索引与检索

知识星球官方帮助中心 doc.zsxq.com 提供 AI 可读的 markdown 版本。

## 索引位置

https://doc.zsxq.com/llms.txt

符合 [llmstxt.org](https://llmstxt.org) 规范，按栏目列出全部文档，每条形如：

```
- [标题](https://doc.zsxq.com/<slug>.md): 简介
```

llms.txt 自带「面向 AI 工具」与「引用建议」两节，其中的约定**优先遵守**。

## URL 约定

| 用途 | 格式 | 说明 |
|-----|------|------|
| 给用户看 | `https://doc.zsxq.com/<slug>.html` | 网页版，可点击浏览 |
| 给 AI 读 | `https://doc.zsxq.com/<slug>.md` | 纯 markdown，体积约 0.5% |

同一篇文档改后缀即可互转。`.md` 体积约为对应 `.html` 的 0.5%（约 200 倍差距，数字以 llms.txt 原文为准），务必读 `.md` 版本。

### Frontmatter

每份 markdown 顶部：

```yaml
---
title: "文档标题"
source: https://doc.zsxq.com/<slug>.html
updated: 2025-01-15T10:30:00.000+08:00
---
```

- `source` — 规范网页地址，向用户引用时用它
- `updated` — 用于判断多篇文档冲突时哪份更新

## 栏目结构

**以 llms.txt 实际内容为准**，下列为撰写时的栏目，仅供预判去哪个栏目找，不要当成固定清单。

「全部栏目文档」下每个一级栏目还有一层子栏目（撰写时如下），定位时优先落到子栏目：

- **我是星主** — 星球创建与设置 / 内容发布及管理 / 星球运营及增长 / 成员管理 / 收入提现与税务 / 数据与分析
- **我是用户** — 注册登录与账号管理 / 星球使用 / 支付退款与发票
- **企业认证**
- **支付与退款**
- **星球公告及相关协议** — 星球公告 / 相关协议
- **星球故事** — 关于知识星球 / 星主案例 / 星友故事
- **其他文档**

栏目、子栏目和篇数会随文档站更新变化；若实际读到的与此不符，按实际的走。

另有两节可优先扫描定位高频问题：

- **核心栏目** — 主要业务分类入口
- **重点文档** — 高频问题文档

## 检索流程

1. WebFetch `https://doc.zsxq.com/llms.txt`
2. 先扫「核心栏目」「重点文档」，未命中再扫「全部栏目文档」
3. 按栏目 + 标题关键词定位，选 **1-3 篇**最相关的
4. WebFetch 对应 `.md` 链接读正文
5. 按 [answer-policy](answer-policy.md) 判断边界、组织回答、标注来源

### 选文档原则

偏少不偏多。3 篇读不出答案，说明关键词错了，回索引重新定位，而不是继续加篇数。

**例外 —— 同题多版要防过期**：费率、手续费、提现、公告、协议这类问题，站内常有多篇标题雷同、slug 极像的历史版本（如「调整个人星球手续费」就有公告、通知、公示、旧版资费等多篇并存）。这类问题**即使已命中 1 篇，也要回索引扫一遍是否有同题文档，比对各篇 frontmatter `updated`，按最新的那篇作答**，避免抓到旧版给出过期数字。冲突处理见 [answer-policy](answer-policy.md) 情况 D。

### 索引或正文拉取失败

WebFetch `llms.txt` 或某篇 `.md` 失败（网络异常、站点改版、地址失效）时：

- 直说当前无法访问帮助中心，**不要**凭记忆或印象作答
- **不要**猜 slug 拼 URL 去碰运气（这正是 answer-policy「不臆造链接」禁止的）
- 引导用户稍后重试，或联系官方客服

这条优先于「先给答案」——够不到文档时，宁可不答。
