# 跨星球检索与问答（search-across-groups）

在多个已加入星球中检索同一问题，逐星球读取、去重和精读，给出带来源与覆盖范围的回答。全程只读。

## 适用意图

- 「在我这些星球里找找关于 X 的讨论」
- 「比较几个星球对 X 的观点」
- 「跨星球查一下某人最近讲了什么」

## 不适用情况

- 已明确一个星球 → 用 [topic-search](../topic-search.md) 或 [summarize-search-results](summarize-search-results.md)
- 只查看自己的跨星球足迹 → 用 [user-footprints](../user-footprints.md)
- 需要全量统计或精确计数 → 本场景只覆盖实际读取范围，不把首批结果当全量

## 所需输入

| 输入 | 必填 | 说明 |
|------|------|------|
| 搜索内容 | **是** | 话题、名称或具体问题；多个名称分别查询，不拼成一个关键词 |
| 星球范围 | 否 | 未指定时按名称和简介选择相关星球；目录可见不等于内容可读 |
| 首批规模 | 否 | 默认最多 5 个星球、每个星球一页；扩大范围前先说明并确认 |

## 使用的原子操作

| 操作 | reference | 作用 |
|------|-----------|------|
| `group +list` | [group-list](../group-list.md) | 确定候选星球和真实 `group_id` |
| `topic +search` | [topic-search](../topic-search.md) | 逐星球语义或关键词检索 |
| `topic +detail` | [topic-detail](../topic-detail.md) | 精读筛选后的相关主题 |
| 分享链接 | [share-links](../share-links.md) | 给出来源星球和主题链接 |

## 执行流程

1. 从目录确定范围；未指定时按名称、简介选择，不默认遍历全部星球。
2. 逐星球调用 [topic-search](../topic-search.md)，分别填写真实 `group_id`。首批最多 5 个星球、各一页；话题优先语义检索，确切名称或需筛选翻页时用关键词检索。
3. 按 `topic_id` 去重并保留来源；精读入选主题后再比较或摘要，引用注明星球和主题。
4. 输出已查、未查、权限拒绝和截断范围；样本不足时明确结论仅基于已读取结果。

## 分支与停止条件

- 星球名称重名或范围不清 → 列候选让用户确认，不猜。
- 某个星球权限拒绝 → 记录并未查该星球，继续其他已授权目标；不换路径或参数绕过。
- 某星球零命中 → 只表示本次查询未命中，不等于该星球没有相关内容。
- 首批不足以回答 → 报告缺口，由用户决定是否增加星球、时间窗或页数。
- 检索结果只有摘要 → 精读后再下结论或引用，不把预览当完整正文。

## 用户确认点

- 只读检索和精读不需要逐条确认。
- 超过首批 5 个星球、需要显著扩大时间窗或页数时，先确认范围和成本。

## 完成标准

- 每个实际查询的星球都有真实 `group_id`，没有拼造或合并 ID。
- 引用能对应到已精读主题，并标注来源星球。
- 已查、未查、拒绝和截断范围披露完整；没有把小样本说成跨星球全量结论。

## 失败与回退

- 单个星球失败不影响其他星球；记录失败原因和未覆盖范围。
- 权限拒绝不绕路；参数错误可按对应 reference 修正一次。
- 个别主题精读失败时跳过并标注，不编造正文或观点。
