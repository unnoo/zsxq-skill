# generate-video：内容提炼规则

AI 提炼星球帖子为视频脚本时的**完整规则**。提炼前必须读完本文，违反任何铁律则重写。

## 模板选择

| 模板 | 脚本 | 适用内容 | 页数 | 每页时长 | 总时长 |
|------|------|----------|------|----------|--------|
| 结构化 | `render.js` | 长文（> 400 字）、多要点、有论证过程 | 4 页 | 封面 2s + 内容 5s | 17s |
| 金句型 | `render-minimal.js` | 短观点（≤ 400 字）、金句、情绪共鸣 | 6 页 | 3.5s | 21s |

## JSON Schema（结构化模板）

```json
{
  "planet": "星球名称",
  "author": "作者名（留空则不显示分隔符）",
  "brand_color": "#品牌色十六进制",
  "topic": "视频主题（≤8字）",
  "topic_highlight": "topic中需高亮的关键词（1-3字）",

  "cover": {
    "chip": "星球名 · 第X期",
    "h1": ["封面标题第1行（≤8字）", "封面标题第2行（≤8字）"],
    "h1_accent": 1,
    "sub": "封面副标题（≤20字）",
    "trio": [
      { "label": "关键词（2字）", "desc": "解释（≤5字）", "color": "orange" },
      { "label": "关键词（2字）", "desc": "解释（≤5字）", "color": "orange" },
      { "label": "关键词（2字）", "desc": "解释（≤5字）", "color": "cream" }
    ]
  },

  "scenes": [
    {
      "chip": "场景标签（2-6字）",
      "h1": ["标题第1行（≤8字）", "标题第2行（≤8字）"],
      "h1_accent": 1,
      "sub": "补充说明（≤25字）",
      "items": ["要点1（≤18字）", "要点2（≤18字）", "要点3（≤18字）"]
    }
  ],

  "finale": {
    "chip": "结语标签",
    "h1": ["结论第1行（≤8字）", "结论第2行（≤8字）"],
    "sub": "结论展开（≤30字）",
    "items": [],
    "finale_text": "金句（≤15字×2行，用\\n换行）"
  },

  "cta": null
}
```

> 金句模板 schema 不同：使用 `pages[]` 数组，每页 `text` + `sub` + 可选 `highlight`，无 `cover/scenes/finale` 结构。

## JSON Schema（金句模板）

```json
{
  "title": "视频标题",
  "accent": "#品牌色",
  "pages": [
    { "text": "封面大字", "sub": "副标题", "highlight": "高亮词" },
    { "text": "内容行1\n内容行2" }
  ]
}
```

每个 `page.text` 支持 `\n` 换行，渲染器按字数自动选字号（≥ 120px，字多则缩小）。

## 提炼铁律

违反任何一条 → 重写：

1. **结论先行** — 封面第一页就说核心观点，不要先铺垫再总结
2. **主谓宾完整** — 每行标题必须独立成句，不省略主语（"我选择放弃"而非"选择放弃"）
3. **不用符号代替语义** — 禁止 ≠、→、& 等符号，用文字表达
4. **金句两行对仗或递进** — "做完不算 / 做通才算"、"五百万很多 / 一个事故更贵"
5. **trio 描述 ≤ 5 字** — 绝对不允许换行
6. **topic ≤ 8 字** — 超过必缩短
7. **items 单条 ≤ 18 字** — 超过必拆分或缩短
8. **结语页不要 items** — 只用大字金句（finale_text），清晰有力
9. **数字具体** — "500 万"比"很多钱"好，"3 年"比"很久"好
10. **系列编号** — chip 里带"第 X 期"，建立连续性

## 黑名单

绝对不能出现：

- ❌ 一个字单独掉到下一行
- ❌ "≠"、"→"、"&" 等符号做标题
- ❌ 没有主语的句子做标题
- ❌ 结语页带边框的居中文字
- ❌ "扫码加入"（视频里放不了码）
- ❌ trio 描述超过 5 个字
- ❌ 两行标题必须连起来才能理解的写法

## 质量自查

生成 JSON 后逐项检查以下 7 项，任何一项不通过则修改后再输出：

| # | 检查项 | 标准 |
|---|--------|------|
| 1 | 每行主谓宾完整 | 遮住其他行，这一行单独能看懂 |
| 2 | trio 描述 ≤ 5 字 | 数字数 |
| 3 | topic ≤ 8 字 | 数字数 |
| 4 | 无禁用符号 | 无 ≠ → & |
| 5 | items 单条 ≤ 18 字 | 数字数 |
| 6 | 金句两行对仗 | 读出来有节奏感 |
| 7 | 封面结论先行 | 第一页就能抓住人 |
